# Shimi Ritual · דף הבית החדש

פותחים את `index.html` בדפדפן. שומרים את כל הקבצים והתיקייה `assets` יחד. אין צורך בהתקנה או בחשבון. אפשר גם להעלות את התיקייה לאירוח סטטי כדי לפתוח בטלפון; הגרסה הזו לא פורסמה ברשת.

דף אחד עם בוקר וערב, בחירת יום בשבוע הנוכחי וסימון שלבים. לחיצה על שם המוצר פותחת הוראות שימוש. לחיצה על העיגול מסמנת שבוצע. כפתור הסיום מסמן רק את שלבי הבסיס, ואינו טוען שהשתמשת במוצרים לבחירה.

הסימונים נשמרים בדפדפן הנוכחי לכל תאריך וזמן ביום. אין סנכרון בין מכשירים ואין שרת או כלי מעקב. אם שמירה חסומה, הסימונים נשארים בזיכרון עד סגירת הדף ומופיעה הודעה. בחצות עוברים ליום החדש. הזמן המוצג נבחר אוטומטית לפי השעון: בוקר לפני 18:00 וערב לאחר מכן; אפשר לבחור ידנית בכל רגע. זו תצוגה בלבד, לא הוראה למרוח בשעה מסוימת. אין הבטחה לעבודה במצב טיסה ואין service worker.

השגרה היא הצעה לפישוט. אין שינוי אוטומטי בתרופת המרשם או בתדירות האזלאית. התאמת תרופת מרשם, כולל שימוש בצוואר, היא עם הרופא/ה. ראו את `routine-review.md` להנמקה ולמקורות.

המקור נשמר בנפרד בתיקיית `original-v30` בסביבת העבודה; קובץ ה־ZIP שסופק לא שונה. הפונט Rubik מצורף עם רישיון OFL בתיקיית `assets`. האיורים והאייקונים המקוריים נלקחו מקובץ המקור.
